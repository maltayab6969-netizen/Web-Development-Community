## 📚 عن الدورة

دورة عملية للمبتدئين تماماً، بدون أي خبرة سابقة. بنتعلم كيف نبني مواقع حقيقية خطوة بخطوة، بالتطبيق العملي وليس الحفظ.

### الدرس الثاني: عناصر المحتوى في HTML

الدرس الحالي في المنصة يغطي:

1.  **مقدمة جذابة** للدرس
2.  مراجعة هيكل HTML والتركيز على `<body>`
3.  شرح العناوين من `<h1>` إلى `<h6>`
4.  شرح الفقرات باستخدام `<p>`
5.  شرح الروابط باستخدام `<a>` و `href` مع مثال Google
6.  شرح الصور باستخدام `<img>` وخصائص `src` و `alt`
7.  تطبيق عملي لإنشاء صفحة شخصية كاملة
8.  عرض النتيجة الفعلية داخل المتصفح
9.  تحدٍّ عملي للطلاب - إنشاء صفحة شخصية
10. خاتمة تحفيزية للدرس الثالث

## ✨ مميزات المنصة التفاعلية

- 🎨 **هوية بصرية احترافية:** خلفية داكنة بأسلوب VS Code مع إضاءة زرقاء وبنفسجية
- 💻 **محرر كود حي:** أكواد تُكتب تدريجياً أمام الطالب مثل الفيديو الحقيقي
- 🌐 **معاينة متصفح حية:** نتيجة كل مثال تظهر فوراً في متصفح وهمي
- ↔️ **اتجاه صحيح للأكواد:** كل الأكواد LTR من الشمال لليمين - `<h1>` على اليسار و `</h1>` على اليمين - بدون انعكاس
- 🇸🇦 **عربي RTL:** كل الشروحات بالعربية RTL، والأكواد بالإنجليزية LTR
- 📱 **متجاوب مع الجوال:** يعمل على الكمبيوتر والجوال
- 🎤 **وضع المذيع:** صفحة منفصلة للمدرب للتسجيل بدون أن يراها الطلاب
- 📋 **نسخ الكود:** زر نسخ لكل مثال

## 🎯 التحدي العملي للطلاب

أنشئ صفحتك الشخصية باستخدام ما تعلمته:

```html
<h1>اسمك هنا</h1>
<p>نبذة قصيرة عنك</p>
<a href="https://google.com">موقعي المفضل</a>
<img src="profile.jpg" alt="صورتي الشخصية">
```

أرسل كودك في مجموعة التدريب على واتساب، وسيتم عرض أفضل صفحة في الدرس القادم.
